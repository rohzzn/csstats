Add to Steam
  1. Click Add to Steam. The Chrome Web Store opens right here, inside Steam.
  2. Click Add to Chrome, then Add extension.
  3. Open any Steam profile. The stats appear under it.

Add it to Steam

Steam only lets you add it from inside Steam. In-game it takes ten seconds:

  1. In CS2, press Shift + Tab and open the web browser.
  2. Go to csstats.rohan.my
  3. Click Add to Steam, then Add to Chrome.
